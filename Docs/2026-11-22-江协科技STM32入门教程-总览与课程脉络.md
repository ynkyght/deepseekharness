## 0. 结论先行

1. 这套教程 = **15 章 / 43 个 Keil 工程 / 207 页课件**，主线是 GPIO → OLED → 外部中断 → 定时器（PWM/输入捕获/编码器）→ ADC → DMA → 串口 → I2C → SPI → BKP/RTC → 低功耗 → 看门狗 → 内部 Flash，全部基于 **标准外设库 V3.5.0（不是 HAL、不是 CubeMX）**。
2. 每个工程都是同一套「Start + Library + User + System + Hardware」模板的拷贝；新开一章只需复制工程、换 `main.c` 与 `Hardware` 下的模块文件（§4）。
3. 例程是**教学骨架**：轮询/阻塞为主（`Key_GetNum` 按住不放会卡住），中断里只置标志，没有 RTOS、USB、CAN、SDIO、FSMC、错误恢复与低功耗实测（§1 边界）。
4. 接线是一套固定的面包板方案，**跨章复用严重**（PA0 同时是 PWM、AD、TIM2_ETR、WKUP）；照抄单章没问题，合并多章前必须先查《引脚接线与模块资料》§3。
5. 官方在 `程序修改说明.pdf` 里公开了 6 处改动，全部是「现象→根因→修法」型：不照做会踩「一次边沿触发多次中断」「软件 I2C/SPI 移植后偶发错位」。

## 4. 工程模板与编译配置（可按此复现）

### 4.1 目录与分组

```
2-1 STM32工程模板/
├─ Start/      startup_stm32f10x_md.s、core_cm3.c/h、stm32f10x.h、system_stm32f10x.c/h
├─ Library/    misc.c + stm32f10x_*.c（标准外设库 V3.5.0）
├─ User/       main.c、stm32f10x_conf.h、stm32f10x_it.c/h
├─ System/     Delay.c/h（各章按需加 Timer.c、Store.c、MyFLASH.c、MyRTC.c）
├─ Hardware/   各章模块：LED/Key/Buzzer/LightSensor/CountSensor/Encoder/OLED/PWM/Motor/Servo/IC/AD/Serial/MyI2C/MySPI/MPU6050/W25Q64
├─ DebugConfig/ 调试器配置
├─ Objects/、Listings/  编译产物（可删）
└─ Project.uvprojx/.uvoptx
```

- 实际被调用的模块以 `main.c` 的 `XXX_Init()` 为准；**工程里带的文件不一定被调用**（如 5-2、10-1 里有 `Key.c` 但没调 `Key_Init`）。
- `1-2 keilkill.bat` 用来清 Objects/Listings，拷贝工程前跑一次可显著减小体积。

### 4.2 关键工程选项（从 `6-1` 的 `Project.uvprojx` 读出）

| 项 | 值 | 说明 |
|---|---|---|
| Device | STM32F103C8（STMicroelectronics） | 对应 DFP 里的中容量型号 |
| Cpu / 存储 | IROM 0x08000000 大小 0x10000（64 KB）；IRAM 0x20000000 大小 0x5000（20 KB） | C8T6 的真实容量 |
| Define | `USE_STDPERIPH_DRIVER` | 不开则 `stm32f10x_conf.h` 不生效 |
| IncludePath | `.;.\Start;.\Library;.\User;.\System;.\Hardware` | 五段全加，缺一则找不到头文件 |
| 编译器 | ARMCC5（`uAC6=0`），Optimization Level 1 | 教程时代的默认；用 AC6 可能出告警 |
| Hex 输出 | `CreateHexFile=0`（默认不生成 hex） | FlyMcu 串口下载需要 hex，需手动勾选 |
| 调试器 | `BIN\UL2CM3.DLL`（ST-Link） | Flash Download 里勾 Reset and Run |

### 4.3 新建工程 6 步（课件页 16 原文要点）

1. 建工程文件夹，Keil 新建工程并选型号；
2. 在工程文件夹里建 Start、Library、User 等目录，把固件库文件复制进去；
3. 工程里建同名分组，把文件加入分组；
4. C/C++ → Include Paths 声明所有头文件目录；
5. C/C++ → Define 填 `USE_STDPERIPH_DRIVER`；
6. Debug → 选调试器 → Settings → Flash Download 勾 `Reset and Run`。

### 4.4 启动与中断函数落点（课件页 17）

`startup_stm32f10x_md.s`（复位中断）→ `SystemInit()`（system_stm32f10x.c）→ `main()`；其它中断函数名由启动文件的向量表决定，用户实现放在 `stm32f10x_it.c` 或模块 `.c`（如 `EXTI15_10_IRQHandler`、`TIM2_IRQHandler`、`USART1_IRQHandler`）。函数名差一个字符就永远进不去。
