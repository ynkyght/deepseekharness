## 0. 结论先行

1. 全套例程是**一套固定的面包板接线**：LED PA1/PA2、蜂鸣器 PB12、按键 PB1/PB11、光敏 PB13、对射式 PB14、旋转编码器 PB0/PB1、OLED PB8/PB9、串口 PA9/PA10、SPI PA4–PA7、软件 I2C PB10/PB11、ADC PA0–PA3。
2. **引脚跨章复用严重**：PA0 同时是 6-3 的 PWM 输出、7-x 的 AD0、6-2 的 TIM2_ETR、13-4 的 WKUP；PA1/PA2 既接 LED 又是舵机/电机 PWM。合并多章例程前必须先查 §3。
3. 每章都有实拍接线图 `1-1 接线图/<工程名>.jpg`，是「这章怎么接」最快、最可靠的一手资料（本文表格均由其同名源码反推，二者应一致）。
4. 模块资料里真正会被反复查的是：**核心板原理图/数据手册、OLED 数据手册与取字模软件、MPU6050 PS/RM 手册、W25QXX 手册、TB6612 手册、ITR9606/TCRT5000 手册**（§4）。

## 3. 引脚冲突与复用（合并例程前必查）

| 引脚 | 教程里被谁用过 | 备注 |
|---|---|---|
| PA0 | 6-2 TIM2_ETR；6-3 PWM_CH1；6-6/6-7 PWM 激励输出；7-1/7-2/8-2 AD0；13-4 WKUP | 同一时刻只能选一种用途 |
| PA1 | 3-x LED1；6-4 PWM_CH2（舵机）；7-2/8-2 AD1 | LED 与舵机 PWM 抢脚 |
| PA2 | 3-x LED2；6-5 PWM_CH3（电机）；7-2/8-2 AD2 | 同上 |
| PA3 | 7-2/8-2 AD3（3-4 按键例程未用） | — |
| PA4、PA5 | 11-x SPI SS/SCK；6-5 电机 IN1/IN2 | SPI 与电机驱动抢脚 |
| PA6 | 6-6/6-7 输入捕获；6-8 编码器 A 相；11-x SPI MISO | — |
| PA7 | 6-8 编码器 B 相；11-x SPI MOSI | — |
| PA9、PA10 | 9-x 串口；13-2 睡眠唤醒 | 串口调试口 |
| PB1 | 3-4/14-x 按键 2；5-2 编码器 B 相 | 按键与编码器抢脚 |
| PB11 | 3-4/14-x 按键 2；10-x I2C SDA | 按键与 I2C 抢脚 |
| PB8、PB9 | 4-1 起全部带 OLED 的工程 | OLED 常驻，注意别被复用 |

- **未调用不等于冲突**：5-2、10-1、11-1 等工程目录里带 `Key.c`，但 `main.c` 没有调 `Key_Init`，所以 PB1/PB11 不会被配成按键——判断冲突要以 `main.c` 的初始化调用为准。
- PB3、PB4、PA15 默认是 JTAG 脚，要当 GPIO 必须 `GPIO_PinRemapConfig(GPIO_Remap_SWJ_JTAGDisable, ENABLE)`（6-3 的 PWM.c 里保留了这段注释示例，未启用）。
- PA13/PA14 是 SWD 调试脚，教程未占用；自己改板时别动。
